# 📈 Stock Market Price Tracker with Voice Assistant

This Python project allows users to:
- Fetch real-time stock prices using `yfinance`
- Visualize stock price trends with `matplotlib`
- Use voice commands to interact
- Get audio feedback using `pyttsx3`

## 🔧 Features
- Voice command support
- Real-time stock tracking
- Price threshold alert with voice feedback
- Data visualization (7-day trend)

## 🛠️ Technologies
- Python 3
- yfinance
- matplotlib
- pyttsx3
- SpeechRecognition

## 🖥️ How to Run
```bash
pip install -r requirements.txt
python main.py
